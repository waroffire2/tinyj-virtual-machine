# TinyJ Virtual Machine

A Java-based virtual machine extension developed as part of a compiler course project.

This project extends an existing TinyJ compiler framework by implementing missing virtual-machine instruction behavior for arithmetic, comparison, control flow, stack operations, method calls, and input/output.

## Implemented Instruction Categories

- Arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Modulo

- Logical operations
  - AND
  - OR
  - NOT

- Comparison operations
  - Equal
  - Not equal
  - Less than
  - Less than or equal
  - Greater than
  - Greater than or equal

- Control flow
  - Jumps
  - Conditional jumps
  - Method calls
  - Returns

- Stack and memory operations
  - Push values
  - Load addresses
  - Save values
  - Pass parameters

- Input and output
  - Integer output
  - String output
  - New-line output
